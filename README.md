# AI Infrastructure Lab

AIインフラストラクチャに関する学習・検証・実験を記録するリポジトリ。

## Learning Topics

### 01. Kubernetes
- Cluster / Node / Pod
- Deployment / Service
- Resource Management
- Scheduling / Scaling

### 02. KubeAI
- Architecture
- Model Operator
- Model Proxy
- Model Deployment
- CPU / GPU Resource Profiles

### 03. LLM Inference
- vLLM
- Ollama
- llama.cpp
- Continuous Batching
- KV Cache

### 04. Distributed Inference
- Data Parallelism
- Tensor Parallelism
- Pipeline Parallelism

### 05. Distributed Training
- PyTorch Distributed
- DistributedDataParallel
- DeepSpeed
- NCCL

### 06. GPU Computing
- GPU Architecture
- CUDA
- GPU Memory
- GPU Communication

## Learning Policy

- Understand the architecture before memorizing commands.
- Verify concepts through hands-on experiments.
- Record experiment results and observations.
- Connect AI infrastructure concepts with distributed computing and data platforms.
